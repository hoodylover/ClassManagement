# 👑 우리반 레벨업! (Class Management & Gamification Platform)

> **초등학교 6학년 학급경영과 게이미피케이션을 결합한 스마트 학급 운영 웹 애플리케이션**  
> 학급 화폐를 중심으로 학생이 주도적으로 활동하고, 1인 1역 완수를 통해 경험치와 레벨을 올리며 성장하는 구조입니다.

---

## ✨ 핵심 기능

### 1. 🎒 학생 모드 (Student Dashboard)
- **영웅 프로필 & 자산 카드:** 내 아바타, 칭호 뱃지, 실시간 골드(G) 잔액, 레벨(Lv.1~6) 및 경험치 게이지 바 제공
- **오늘의 1인 1역 (오늘 할 일):** 배정받은 학급 임무 확인 및 `[오늘 임무 완료하기]` 버튼 클릭 시 **도장 애니메이션 + 효과음 + 폭죽 파티클**과 함께 일일 화폐 및 EXP 지급
- **학급 상점:** 모은 골드로 다양한 학급 쿠폰(자리 우선 선택권, 숙제 면제권, 급식 1등 줄서기권 등) 구매
- **내 가방 (인벤토리):** 보유 중인 쿠폰 목록 확인 및 선생님께 확인 요청 기능
- **화폐 입출금 내역:** 최근 입출금 내역 실시간 확인

### 2. 👨‍🏫 선생님 모드 (Teacher Dashboard)
- **학급 요약 통계:** 전체 유통 화폐량, 오늘 1인 1역 완수율(%), 승인 대기 쿠폰 건수 실시간 집계
- **25명 학생 통합 관리:** 원클릭 `+10G`, `-5G`, `[직접 조정]` 버튼으로 1초 만에 화폐 지급 및 차감, 체크박스 기반 일괄 보너스 지급
- **새로운 하루 시작:** 하루가 바뀌었을 때 버튼 한 번으로 전체 학생의 1인 1역을 '미완료'로 일괄 리셋
- **1인 1역 배정:** 새로운 역할 추가/수정/삭제 및 25명 학생에게 드롭다운으로 손쉽게 배정
- **상점 관리 & 쿠폰 승인:** 상점 아이템 등록 및 학생들의 쿠폰 사용 신청을 확인하고 `[승인 (사용 완료)]` 처리
- **데이터 백업 및 복원:** 안전한 JSON 다운로드, 복원 및 초기화 지원

---

## 🛠️ 기술 스택 (Tech Stack)
- **Front-end:** Vanilla HTML5, Vanilla CSS3 (현대적인 Glassmorphism & 다크/인디고 테마)
- **Script:** Vanilla JavaScript (ES Modules)
- **Audio & Visual:** Web Audio API (합성 효과음 엔진), HTML5 Canvas Confetti (폭죽 효과)
- **Storage:** LocalStorage API (오프라인 및 브라우저 영속화)

---

## 🚀 실행 방법

### 1. 브라우저에서 바로 열기
별도의 설치 없이 [index.html](index.html) 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 바로 실행할 수 있습니다.

### 2. 로컬 웹 서버로 열기 (권장)
Python이 설치된 환경에서 터미널을 열고 다음 명령어를 실행합니다:
```bash
python -m http.server 8080
```
브라우저 주소창에 `http://localhost:8080`을 입력하여 접속합니다.
